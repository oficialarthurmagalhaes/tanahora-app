# 💊 Tá na Hora! — App

Aplicativo mobile de **lembrete de remédios pensado para idosos**. Ele mostra quais remédios devem ser tomados e em que horário, para evitar esquecimentos e trocas de medicamento.

🌐 **Site do projeto:** [tanahora.online](https://tanahora.online/)

## 🛠️ Tecnologias

- [React Native](https://reactnative.dev/) com [Expo](https://expo.dev/) (Expo Router)
- TypeScript

## ▶️ Como rodar o projeto

```bash
# 1. Instale as dependências
npm install

# 2. Inicie o app
npx expo start
```

Depois, abra no celular com o app **Expo Go** (lendo o QR Code) ou em um emulador Android/iOS.
